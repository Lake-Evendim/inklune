# 八套过渡方案比较核验与修复

用户指的是 `/?experiences` 中的八种过渡，并非 `/?designs` 的八套开始页风格。当前正式构建为 `index-ChtVksrF.js` / `index-DC7CTKeC.css`。

## 发现与修复

过渡比较的 `ExperienceGallery` 在同一 iframe 内更新组合，使用正式 `App`、`StartPage`、`CrispWordmark` 与 `useRoomTransition`。高清轮廓、点写、完成衔接与快照修复本已共用。

实测发现手机预览缩小后，画布只有 354×97 个物理像素。此前从当前画布的墨迹判断可见行程，低分辨率量化把细的交叉误判成隐藏回拉，15ms 原始行程被压成 6.24ms，等效推进速度再次达到相邻段的三倍。

`wordmarkReveal.ts` 现从固定 1040×284 的原始 SVG 尺度推导一次共用的弧长时钟。每种显示密度仍计算自身高清墨迹覆盖与揭示几何，但它们共用同一节奏。参考画布计算后释放，只保留小型时间映射；改变窗口、DPR、主题或 iframe 缩放不会重新分配书写时间。Borel 字形、点写220ms、整词2310ms、完成时钟及过渡样式保留。
