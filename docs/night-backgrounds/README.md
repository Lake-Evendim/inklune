- 雾棕夜色（Hazy）：烟褐和炭黑的宽柔雾带。
- 乌木余晖（Ebony）：更暗的黑棕底，只留两道暖光。
- 暗金流光（Golden）：低亮度琥珀金斜向漫射。
- 另有午夜棉纸、暖灰亚麻、炭黑麂皮、蓝灰石板、烟熏胡桃，以及当前石墨参照。

渐变背景采用 2560×1600 横版与 1600×2400 竖版无损 WebP，独立 1024px 颗粒层保持显示尺度。其他材质使用 2048×2048 无损周期纹理。工具脚本 tools/build-night-atmospheres.py、tools/build-night-materials.py 可重新生成。

预览使用固定示例稿件、关闭声音且 persist=false；正式应用仍使用当前石墨，不新增默认设置或材质选择入口。预览链接支持 texture/view 参数，切换材质时同步地址，可直接重开同一效果。
