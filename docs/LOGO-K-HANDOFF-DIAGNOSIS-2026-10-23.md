# k 书写与结束顿挫：定位报告

本轮仅诊断，未修改 Wordmark、CrispWordmark、正式 CSS、字体、时间参数或构建产物。实测对象为 5174 的 `index-B9kCGE_8.js`，不是历史截图或开发页。使用独立 Chrome 147 配置，无需操作用户浏览器或稿件。

## 1. k 有两段可见墨迹停滞

对当前生产 SVG 进行 730–1140ms、每 1ms 一次的 411 个采样，并核对 11 张实际浏览器中间帧。

- 975–997ms：新墨迹增长与消失均为零，23 个连续采样完全不变。
- 1002–1023ms：每毫秒新墨迹增长不足一个等效物理像素，持续约 22ms。截图中右侧小环尚未开始明显展开。
- 后续右侧小环、下行连笔又恢复推进。因此表现为写竖杆、停住、再突然继续，视觉速度不连续。

对应 `src/Wordmark.tsx:24–25`：第二段 `M341.8 70V261L342 209` 写到底后，在已经完成的竖杆内回拉 52 个 SVG 单位；第三段起笔又穿过已经显示的竖杆与交叉区。线性动画按整条路径长度分配时间，包含了这些没有新墨迹的路程。不是 Borel 原始字形本身断裂。

第三至第四段的笔宽为 24→30，但本轮交界处只测到约 3.69 个等效像素的起笔补显；没有证据将其当成主要原因。

修复方向：保留 Borel 外轮廓，调整回拉及交叉段的揭示进度，让可见笔迹在转向处连续推进，并验证中间帧。仅统一加速无法消除这两段停滞。

## 2. 结束切换没有等待真实动画完成

`src/CrispWordmark.tsx:31` 从 layout effect 开始计时，2380ms 后设置完成；CSS 书写动画从浏览器建立动画时间线后开始，两者起点不同。初始化时还会同步生成高清画布，首次绘制及其他长任务会拉开两个时钟。

三次自然播放的真实 CSS 时间如下，均未手动 seek：

| 自然播放 | 切换时最后一段的动画时间 | 真实终点 | 仍差多少 |
| --- | ---: | ---: | ---: |
| 1 | 1700.002ms | 2310ms | 609.998ms |
| 2 | 1733.304ms | 2310ms | 576.696ms |
| 3 | 1666.608ms | 2310ms | 643.392ms |

切换时最后一段仍处于 running 状态；其 active progress 尚为 null，即尚未进入最后一段书写。测试环境的初始化长任务约 451–509ms，之后还有其他长任务；延迟数值取决于设备与负载，不代表每次打开都相同。

额外冷启动在切换瞬间暂停 CSS 时钟，取得了实际浏览器截图：当时只走到约 916.737ms，k 尚未完成，完成层已经显示整词。暂停仅发生在切换之后，用于保留证据，没有改动切换前的生产逻辑。

修复方向：完成状态依赖真正的末段 animation.finished / animationend，并处理重播、减少动态效果与卸载；不能用另一个固定延时猜测书写完成。

## 3. 真正写完后，两个渲染层仍不一致

在独立测试页中将所有书写动画 seek 到 2310ms，固定背景、位置、字号和像素密度，分别显示完成的 SVG 与生产静态画布，拍摄实际屏幕；另取透明像素数据分离遮罩影响。

SVG 使用遮罩栅格化；静态画布使用无遮罩原始轮廓、4 倍采样、面积平均与 pixelated 合成。外框相同并不能保证实际墨迹一致。

| DPR | 实际墨迹重心纵向变化（物理像素） | 边缘平均 alpha 差（0–255） |
| --- | ---: | ---: |
| 1 | +0.386 | 37.607 |
| 1.25 | +0.449 | 39.718 |
| 1.5 | +0.470 | 43.852 |
| 2 | -0.425 | 51.208 |

重新等待布局与画布稳定后复拍，数据一致。SVG 的几何矩阵与画布预期矩阵最大误差小于 0.000005 物理像素，外框没有位移；但屏幕栅格的覆盖与相位不同，因此产生轻微的视觉偏移和变粗感。DPR2 还观察到静态画布相对自身原始像素整体提前一行的合成相位，DOM 矩阵仍相同。后续须用实际屏幕像素验证，不能只检查 getBoundingClientRect。

DPR1.25 时，仅去掉完成 SVG 的遮罩，就会增加约 382.93 个等效像素覆盖；过去“99.9399%”检查只统计近乎不透明的缺墨点，未覆盖这些半透明边缘。真正结束后的 SVG→canvas 切换仍存在约 3718 个 alpha 变化超过 0.1 的屏幕像素。这是独立于提前结束的第二个问题。

修复方向：书写与完成态统一轮廓、栅格相位和覆盖计算，避免最后一刻更换绘制链路。完成事件修复与渲染一致性修复需要分别验收。
