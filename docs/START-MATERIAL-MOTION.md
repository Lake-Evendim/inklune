# Inklune 留白：材质、主题与场景过渡

2026-10-22。主开始页沿用 01 留白，大幅 Borel 品牌略高于页面中心。i 点 220ms、正文 230ms 起笔、整词 2310ms 与现有精修路径保持一致。

## 材质与界面

日间背景是六张实际纸纹，夜间统一为石墨黑。开始页和书写室都使用明确的材质层，页面底色透明；新版资源使用 `-v2` 文件名，避免继续命中旧的低对比素材缓存。纹理增加纸浆起伏、疏朗纤维和细颗粒，避免规则点阵或密集孔洞。

| 纸张 | 底色 | 材质方向 |
| --- | --- | --- |
| 纯白细棉 | #fafaf7 | 中性白，细棉与柔软压纹 |
| 暖白纤维 | #f7f5ed | 轻暖白，疏朗细纤维（默认） |
| 象牙纸浆 | #f4efdf | 温润象牙色，缓慢纸浆起伏 |
| 米色手工纸 | #eee7d9 | 浅米色，天然纤维与哑光起伏 |
| 细纹布纸 | #f4f1e8 | 暖灰白，非规则经纬纹 |
| 平滑书纸 | #f9f7f0 | 平滑暖白，细颗粒与轻薄书页 |
| 石墨黑（夜间） | #202122 | 细腻中性石墨，低亮度压纹 |

七张材质均为 2048×2048 无损 WebP，以 1024 CSS 像素平铺。周期性多尺度随机场和跨边界纤维避免可见拼接线。生成器在 `tools/build-start-materials.py`，材质参数在 `public/start-materials/manifest-v2.json`。

![当前材质样本，非网页截图](material-v2-proof.png)

书写室周围采用同一套纸白／石墨配色：日间深灰绿文字、柔白工具面板；夜间柔白文字、中性灰工具面板。页眉保存状态、右上字数、菜单、设置、导出与信盒一起切换。桌面工具栏显示短标签，手机保留薄底栏，把主要纵向空间留给纸页。

开始页与书写页只读同一个夜间设置。比较预览的主题也双向同步；采用组合同时采用其昼夜状态。预览本身使用独立示例纸页，不写入真实稿件存储。

## 已阅读的官方动效资料

1. [Apple HIG — Motion](https://developer.apple.com/design/human-interface-guidelines/motion)。通过官方文档 JSON 阅读。参考简短精确的反馈、允许取消动作、符合预期的返回方向，以及减少动态效果支持。
2. [Material Components — Motion](https://github.com/material-components/material-components-android/blob/master/docs/theming/Motion.md)。读取官方源码文档中的 Container transform 与 Transitions。参考用源和目标边界建立空间联系，保留共享元素与源场景，进入／返回使用相应方向。
3. [Fluent 2 — Motion](https://fluent2.microsoft.design/motion)。读取正文。参考自然惯性、尺寸与时长的关系、层级编排和短延迟；页面内部避免无目的的大幅搬移。
4. [MDN — View Transition API](https://developer.mozilla.org/en-US/docs/Web/API/View_Transition_API)。参考共享元素与场景快照保持上下文，以及焦点、阅读位置和临时视图的清理。当前实现使用 Web Animations API，没有宣称采用浏览器 View Transition API。

## 八套可比较方向

过渡不限于书写隐喻；同时探索品牌、物体、空间、镜头焦点和光线。所有方案只改变场景外层和临时快照，内部纸页、机械、墨迹与灯光坐标保持稳定。

| 方案 | 时长 | 动作与气质 |
| --- | --- | --- |
| 从入口展开（默认） | 660ms | 从入口圆角边界展开至全屏，明确且克制 |
| 墨迹归位 | 820ms | 中央品牌沿弧线缩入页眉，建立品牌连续性 |
| 落纸成景 | 840ms | 入口先展开至纸页边界，再显露页眉和工具 |
| 墨晕舒展 | 850ms | 可插值的有机贝塞尔轮廓扩散，柔软且富有流动感 |
| 对开留白 | 860ms | 两片封面沿中央分开，轻微透视带来空间层次 |
| 轻掀封面 | 780ms | 封面向上抬起并离开，书写室保持原位 |
| 景深溶入 | 740ms | 前景虚化退去，书写室逐渐进入清晰焦点 |
| 柔光掠过 | 800ms | 渐软光线边界与低强度柔光扫过场景 |

品牌／封面快照冻结点击当时的笔画进度，保留遮罩并为 SVG 引用生成独立 ID，避免提前露出完整连笔或产生重复引用。临时视图保持 inert／aria-hidden，不拦截输入；结束、取消或切换预览时移除。

返回反向执行相同的关键帧；中途返回从当前透明度、变换与裁剪接续。窗口变化时完成当前动画，减少动态效果开启时直接进入。旧动效偏好失效时回到保留的“从入口展开”，材质偏好继续保留。

## 提前准备与比较

App 常驻一个完整编辑室。开始页背后提前加载字体、纸材，建立当前机械套件、弯曲纸页和照明首帧。就绪键绑定稿件 ID、纸张、字号、形状、套件与昼夜状态，旧配置不能解锁新配置。

隐藏编辑室保持完整测量尺寸及 inert／aria-hidden。准备完成后点击立即开始过渡；极早点击保留开始页并显示准备状态。进入完成后才聚焦输入；返回继续复用稿件、滚动与渲染上下文。

比较入口为 `?experiences`，支持桌面／手机、昼夜、选择组合、进入／返回、重播和采用。切换方案、材质和设备尺寸通过同一个 iframe 更新，避免每次重新加载书写室；“重播起始”才创建新预览。
