# Inklune logo 持续锯齿诊断

2026-10-23。用户要求先定位问题。本轮未修改正式字形、书写动画、TSX/CSS、应用 bundle 或发布包。仅添加隔离诊断页面和证据。

## 结论

本机已复现的持续阶梯感主要处于最终显示链路：居中位置落在物理像素之间，高清 canvas 再由 CSS 缩回屏幕时未主动控制抗锯齿采样。两个因素共同影响曲线边缘覆盖。去除遮罩、仅改成 SVG、仅提高画布分辨率均不足以解决。

实际对照中，物理像素对齐改善了当前 canvas 和无遮罩 SVG；按屏幕尺寸主动缩小并同时对齐位置的方案，边缘覆盖更均匀。此为诊断方向，尚未进入生产实现。不能据此断言浏览器内部使用了某个特定插值算法，也不能把局部量化差异称为整体视觉质量的百分比提升。

## 正式页面实测

- 地址：`http://127.0.0.1:5174/?experience-preview&material=milk&transition=aperture`，独立预览，未经过比较页 iframe 的整体缩放。
- 构建：`index-Crnu6QyE.js`、`index-CXMbKhhi.css`；最终高清 canvas 已启用，SVG opacity 为 0。
- DPR：1.25；网页 1536 × 639 CSS 像素；真实截图 1920 × 799 像素。
- logo 显示：820 × 223.75 CSS 像素，即 1025 × 279.6875 物理像素。
- canvas backing：2460 × 671。宽度缩小比例为 2.4，源画布清晰不等于最终屏幕边缘覆盖准确。
- 左上角：358、185.350006 CSS 像素，约 447.5、231.687508 物理像素。
- `CrispWordmark.tsx` 通过 `clientWidth` 及固定 3–4 倍 CSS 像素生成画布；`.wordmark-hd` 再按 100% 容器尺寸显示。当前中心布局没有对齐物理像素网格。

## 排除与范围

- 正式构建、高清 canvas 的启用均已实测，排除“旧版本仍在显示”以及“高清层没有启用”。
- 七条 Borel 轮廓与原字体导出逐一核对，仍使用 Q/C 贝塞尔曲线。最大坐标舍入误差约 0.000500 SVG 单位，在本次尺寸下不足 0.0004 CSS 像素，无法解释可见阶梯。
- 固定平色背景仍可复现，纸纹不是本次持续锯齿的必要条件。
- 完成的书写遮罩与无遮罩 SVG 在所测 k/l 曲线区域像素一致，遮罩不是该区域终帧持续锯齿的来源。这不构成对所有动画中间帧的重新验收。
- 本次实际对照只代表当前 Chrome、DPR 1.25、桌面尺寸。后续修复仍需检查其他 DPR、移动端及动画到终帧的衔接。

## 对照方法与结果

隔离页：`/diagnostics/logo-sampling.html`。九个方案使用同一套原始轮廓、820 × 223.75 CSS 尺寸、固定纸色 `#f7f5ed` 和墨色 `#303832`。所有浏览器截图均按真实屏幕取得，没有传入截图宽高覆盖参数。局部裁切为物理像素 `(735,245)-(1000,365)`，展示图使用最近邻放大，保留原像素。

量化参考由原始贝塞尔路径以 32 倍分辨率渲染后按面积缩小，再从固定前景、背景估算截图的边缘 alpha。Cairo 和 Chrome 的渲染器不同，因此以下为局部覆盖差异的比较证据，不是绝对审美评分。

| 方式 | 边缘 alpha 平均绝对差异 |
| --- | ---: |
| 当前高分辨率 canvas | 0.16260 |
| 当前 canvas，仅对齐位置 | 0.09427 |
| 原始无遮罩 SVG | 0.16202 |
| 完成的书写遮罩 SVG | 0.16202 |
| SVG，仅对齐位置 | 0.09658 |
| 按屏幕 DPR 直接绘制 canvas | 0.16708 |
| 按屏幕 DPR 直接绘制，并对齐位置 | 0.09516 |
| 4 倍屏幕采样后主动缩小 | 0.15896 |
| 4 倍屏幕采样后主动缩小，并对齐位置 | 0.03206 |

单独改变采样但保留非像素对齐位置，会出现较软的边缘，不能将变糊误判为修复。单独对齐位置亦有残余覆盖差异。联合处理在本次局部对照中最接近面积覆盖参考。

## 后续修复方向

1. 按最终显示矩形和 DPR 控制物理画布尺寸、显示尺寸和位置，避免在边缘重新发生分数像素合成。
2. 明确采用高质量降采样，再交付与屏幕像素匹配的结果；不继续依赖固定“3–4 倍”源尺寸。
3. 保留 Borel 和逐笔书写，检查 SVG 动画与最终层的位置、轮廓和清晰度衔接。
4. 验证 DPR 1、1.25、1.5、2，浏览器缩放变化及移动端。不得以本轮诊断页的改善替代正式页面验收。
